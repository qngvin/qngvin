# Suggested Commands

## Project Commands
- **Dev server**: `npm run dev` (runs development server on localhost)
- **Production build**: `npm run build` (compiles Next.js optimized bundles)
- **Start production**: `npm run start` (spins up node server for built app)
- **Lint**: `npm run lint` (runs ESLint checks)

## CLI Tools
- **GitNexus Analyzer**: `gitnexus analyze --embeddings` (regenerates knowledge graph)
