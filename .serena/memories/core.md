# Portfolio Qngvin Core

High-end personal portfolio website for Tran Quang Vinh. Focused on minimalist design, micro-animations, theme toggling, and multi-language support.

## Project Structure
- `app/` - Next.js App Router setup (Page components, global styles, root layout, sitemaps).
- `components/` - Global components (UI backgrounds, switchers).
- `features/` - Domain-specific screens and constants (About, Contact, Home, Work).
- `lib/` - Internal helpers and configuration (next-intl config, custom utilities).
- `messages/` - Localization dictionaries (English & Vietnamese).
- `shared/` - Layout and reusable components (Footer, Header, Page Transitions, Previews).
- `utils/` - Global helper functions (date formats, age calculation).
